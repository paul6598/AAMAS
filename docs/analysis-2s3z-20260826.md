## 관찰과 해석

1. **100k 직후의 특징적 함몰(dip)**: v2는 100k에 0.38로 QMIX(0.31)를 앞서다가
   150–200k에서 0.24–0.26으로 되레 후퇴, QMIX가 이 구간에서 역전. λ(0.998^update,
   에피소드당 1 업데이트, 에피소드 ~50스텝)는 ~100–150k에서 사실상 0에 도달 —
   **dip 시점이 셰이핑 소멸 시점과 정확히 일치**한다. 버퍼(5000 에피소드)에는 수집
   당시 λ로 합성된 보상이 남아 있으므로, "버퍼 내 이질적 보상 혼합" 가설(G2)을
   커브가 직접 지지한다. G2(shaping_in_learner) 방향은 옳다.
2. **G1(mask_anneal_t=300000)은 dip보다 늦다**: 함몰이 150–300k에서 일어나므로
   300k에 마스크를 꺼도 이 구간의 손실은 그대로다. G1이 애매하게 나오면
   `mask_anneal_t=150000` 변형을 1런 추가할 가치가 있음.
3. **초반 가속의 실체**: 기본설정(β=0.5, λ_start=0.5)은 50k에서 0.31 vs QMIX 0.22로
   진짜 초반 우위가 있었으나 100k 이후 소멸 + 후반 붕괴. v2는 가이던스를 약화해
   붕괴를 막은 대신 그 우위마저 잃음. 즉 현재 구현에서 "초반 가속"과 "후반 무해"가
   트레이드오프 관계 — 논문은 둘 다 얻었다고 주장하므로, 이 트레이드오프를 깨는
   것(G2가 유력)이 재현의 본질적 과제다.

## 논문 대비 비판적 논점

1. **논문의 final 우위는 통계적으로 무의미, 진짜 주장은 AUC_early**. 2s3z에서
   0.9785 vs 0.9733 (Δ0.005)은 우리 QMIX 시드 간 표준편차(~0.018)보다 작다.
   논문 스스로 MAVEN(0.9814)이 LEHCA final을 이긴다고 보고. 재현 성패의 기준은
   **AUC_early 1.8×** 여부로 두는 게 맞고, 현재 0.75×로 정반대.
2. **재현 QMIX가 논문 QMIX보다 강하다**: AUC 0.332 vs 0.254, Fig.3의 심한 중반 진동도
   우리 런에는 없음. 논문 Table 2 값(lr 1e-3, Adam, batch 128, buffer 5000)을 그대로
   썼는데도 이렇다면, 논문의 LEHCA-QMIX 격차 일부는 **약한 QMIX 베이스라인**에서 나왔을
   가능성이 있다. 같은 하이퍼파라미터에서 우리 베이스라인이 이미 빠르므로 2s3z의
   개선 여지 자체가 논문 환경보다 작다. 다만 AUC_early 기준으로는 paper LEHCA(0.455)까지
   0.12의 headroom이 남아 있으므로 "2s3z는 포화라 볼 게 없다"는 정리는 final에만
   해당하고 AUC_early에는 해당하지 않음 — **2s3z는 논문에서 AUC 격차가 가장 큰 맵**
   (0.455 vs 0.254)이라 초반 가속 주장 검증에는 오히려 핵심 맵이다.
3. **DIAG_A/B가 논문 Table 5와 정면 충돌**: 논문 ablation은 2s3z에서 셰이핑 단독
   0.9753, 마스킹 단독 0.9740 — 어느 컴포넌트도 단독으로 *해*가 되지 않는다.
   재현에서는 셰이핑 단독이 붕괴(500k에서 0.38), 마스킹 단독이 정체(0.53). 500k vs 1M
   차이를 감안해도 괴리가 큼. 해석은 둘 중 하나: (a) 미공개 자유 파라미터(λ 스케줄,
   β, predicate 스케일·정의)가 논문과 실질적으로 다르다, (b) 논문 결과가 해당
   세부사항 없이는 재현이 어렵다. 로그 방증: DIAG_A(λ_min=0.05)의
   `shaped_return_mean`은 0.44까지 감쇠 후 **다시 0.62로 증가** — λ 바닥 × 커지는
   F_t로 셰이핑이 끝까지 남아 A 붕괴의 "잔존 셰이핑 왜곡" 해석과 부합. 반면 v2는
   ~150k에 0.08, ~300k에 사실상 0으로 소멸 (dip 시점과 일치 재확인).
   어느 쪽이든 **supplementary 확보가 최우선 병목**
   (published 2026-05-25, DOI 10.1038/s41598-026-54971-6의 Supplementary Information;
   페이월이면 교신저자 zhuwei929@hotmail.com 문의. "code available upon publication"
   이므로 코드 요청도 근거 있음).
4. **v2는 평가 프로토콜이 논문과 다르다**: 논문은 테스트도 masked greedy
   ("tactical agents select actions using masked greedy … from the latest Commander
   guidance"). v2의 `use_masking_at_test=False`는 편차이며, v2 수치를 "LEHCA 재현"으로
   보고하려면 이 편차를 명시해야 한다. 최종 보고 전에 v2 최종 모델로 masked-test
   평가 1회를 돌려 격차를 수치화해 두는 걸 권장.
5. **state.md의 "v2 0.85–0.90"은 낙관적**: last-10% 평균 기준 0.80/0.83/0.87
   (평균 0.832). 마지막 몇 포인트만 보면 0.85–0.90처럼 보이나 test_nepisode=32의
   포인트당 이항 노이즈(±0.08)가 크다. 판정 지표를 "최근 5개 평균"이 아니라
   last-10% 평균으로 통일하기를 권장 (auc_early.py 방식과도 일치).
6. **기타 구현 편차의 잠재 영향**: `reasoning_effort=low`(논문 미언급, 가이던스 품질
   저하 가능), 응답 캐싱(논문도 언급하므로 무해 추정), predicate 8종과 스케일은
   전부 자작. 특히 predicate 스케일(damage ~10, kill 1.0 등)은 F_t 크기를 통해 λ와
   곱으로 작용하므로 셰이핑 문제의 절반은 여기 있을 수 있음. 실측: 셰이핑 기여는
   에피소드당 최대 ~3.5 (환경 승리 리턴 ~20의 17%) — 초반 학습 신호로는 유의미한
   크기이나 per-step clip(3.0) 포화 여부는 에피소드 합계 로그만으론 판단 불가.

## 권고 (우선순위 순)

1. **G2 계속** — 커브가 가설을 직접 지지. 성공 기준: 100–200k 함몰이 사라지고
   500k에서 QMIX@500k(0.92, 5시드 평균; 기존 참조점 0.85는 seed0 단독) 근접.
   판정 참조점을 0.85→0.92로 상향해야 함.
2. **초반 가속 복원 실험**: G2가 붕괴를 잡으면 β=0.5, λ_start=0.5(기본값)로 되돌린
   G2 변형 1런. v2의 AUC 손실은 가이던스 약화 탓이므로, 붕괴 원인이 제거된 뒤라면
   강한 가이던스로 AUC 우위(≥QMIX 0.33, 목표 0.45)가 나오는지가 재현의 관건.
3. **supplementary/코드 확보 시도** — 자유 파라미터 탐색보다 비용 대비 효과가 큼.
4. 5m_vs_6m 착수는 지지하되, QMIX_5m6m부터 (LLM 불요, 논문 참조점 0.2950/0.0387).
   pymarl 체크포인트 재개 미지원 상태에서 5M 런(잡 2일 한도 초과 확실)은 시드 통째
   재시작이 되므로, 착수 전 `save_model` + load 재개 경로를 점검할 것.
5. 최종 비교표는 시드 표준편차 포함, v2의 test-mask-off 편차 명시.
