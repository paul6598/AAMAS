# 판정: 마스킹 부호 역전의 원인, F_update 민감도, 관측 d_t 비용 (2026-08-29)

2s3z, AUC_early = 첫 200k 구간(논문 Eq.9, 예산 1M의 20%). 250k 단축런의 AUC는 1M 런과
동일 창이라 비교 가능; final은 250k 시점이라 논문 final과 비교 불가. 시드 std 병기.
마스크 통계는 학습 중 로그 마지막 값(forbid_frac = avail 중 하드 금지 비율,
override = β·lnW 틸트가 greedy argmax를 바꾼 비율, q_gap = Q_max − Q_2nd).

## 표 1. 마스킹 진단 (셰이핑 공통: λ 0.5→0 decay 0.9993, learner-λ; 마스크 어닐 150k)

| 런 | Commander | 마스크 어휘 | β | AUC_early | forbid | override | q_gap |
|---|---|---|---|---|---|---|---|
| H6 (=v4) | LLM | 마스킹 없음 | – | **0.388±0.061** (n=3) | – | – | ~0.08 |
| H1 | LLM | full | 0.5 | 0.223 | – | – | – |
| M5 | LLM | strategic (stop·이동 forbid 차단) | 0.5 | **0.143** | 0.2% | **21%** | 0.076 |
| M4 | Rule (forbid 없음) | – | 0.5 | 0.193 | 0 | – | – |
| **M3** | LLM | full | **0.1** | **0.342±0.040** (n=3) | 16–19% | 9–13% | 0.06–0.08 |
| **M6** | Rule | – | **0.1** | **0.402±0.040** (n=2) | 0 | 8–9% | 0.07–0.09 |
| H5 | LLM | full + 탐색편향 | 0.5 | 0.179 | – | – | – |

**결론 ①: 마스킹 해악의 원인은 forbid 내용이 아니라 소프트 틸트의 스케일.**
어휘를 전략 수준으로 줄여 forbid를 거의 없애도(M5) 최악이고, Rule-Commander로
forbid를 0으로 해도(M4) 나쁘며, **β만 0.5→0.1로 낮추면(M3/M6) 마스킹을 켠 채 마스킹
없음(H6) 수준을 회복**한다. 기전: β·lnW ≈ 0.35–0.55가 초반 Q 격차(0.06–0.09)의 5–8배라
greedy 선택을 LLM 선호가 결정(M5 override 21%). β=0.1이면 틸트 0.07–0.16으로 Q 격차와
같은 자릿수 → "moderate but systematic" 보정이 된다. **권장 β ≤ 0.1.**
논문 Table 5의 "마스킹 제거 시 하락"과 우리 초기 관측의 부호 역전은 우리 β=0.5 추정값
때문일 가능성이 높다 (논문 β 미공개 — 저자 회신으로 검증).

## 표 2. F_update 스윕 (v4 설정: shaping-only, 전체상태 d_t)

| F_update | AUC_early (시드별) | 평균 |
|---|---|---|
| 100 | 0.384, 0.350 | 0.367±0.017 |
| 200 (=H6) | 0.314, 0.386, 0.464 | 0.388±0.061 |
| 400 | 0.313 | 0.313 |
| 800 | 0.352 | 0.352 |
| ∞ (첫 가이던스 영구 고정) | 0.291, 0.360 | 0.326±0.034 |

**결론 ②: 2s3z에서 F_update 민감도는 약하다.** F100≈F200(잦은 갱신 무해, 단 LLM
호출 2배·벽시계 증가), 드문 갱신·영구 고정은 −0.04~−0.07 (≈1σ). 연구 세션의 예상
(2s3z는 QMIX가 포화되는 맵이라 headroom이 작음)과 일치 — **적응 스케줄링의 본 무대는
5m_vs_6m**(가이던스 이득이 실재하는 맵)이며, 2s3z 결과는 "비용 절감 축"의 근거로만 쓴다.

결론에 영향이 없었다고 보고할 수 있다.

## 논문 수치와의 비교 (2s3z)

| | 논문 (Table 4/5/6) | 우리 |
|---|---|---|
| QMIX AUC / final(1M) | 0.254 / 0.973 | 0.332±0.045 / 0.963±0.018 (n=5) |
| LEHCA 완전 구성 AUC / final(1M) | **0.455** / 0.979 | v3(β=0.5): 0.234 / 0.975 (n=4); **β=0.1 완전 구성(M3, 250k): 0.342** |
| LEHCA w/o masking AUC | 0.343 | H6/v4: 0.388 (250k n=3), v4 1M: 0.399±0.086 (n=3) |
| Rule-Commander AUC | 0.392 | M6(β=0.1): 0.402 (n=2) |
| LEHCA/QMIX AUC 비율 | 1.79× | v4 1.20×, M3 1.03×, M6 1.21× |
| 마스킹 효과 (완전 − w/o) | +0.11 | β=0.5: −0.17, **β=0.1: −0.05 (노이즈 내)** |

해석:
- **우리 QMIX가 논문 QMIX보다 강해(0.332 vs 0.254)** 비율 상한이 1.37×로 구조적으로
  낮다. 절대값으로는 shaping-only(0.388–0.399)가 논문 w/o-masking(0.343)을 넘고,
  Rule-Commander(0.402)는 논문(0.392)과 일치한다.
- **논문 완전 구성의 0.455는 미달성.** β=0.1로 마스킹 해악을 없앴지만 이득(+0.11)은
  아직 재현되지 않았다(−0.05, 노이즈 내). 남은 후보: β 0.1 미만/스케줄, 논문의 u_t 참조
  consistency 규칙, 조건부 술어 — 저자 회신(β·F·술어·프롬프트) 후 결정.
- 5m_vs_6m 비율(1.59× vs 논문 1.58×)은 이전 캠페인에서 재현됨 (final-report 참조).

## 저자 회신 시 검증 계획
1. β 값 → M3 설정에 그대로 대입해 마스킹 효과 부호 재판정 (250k, 3시드, 1.5h).
2. F_update 값 → 스윕표에 추가.
3. 술어 목록·프롬프트 → 어휘 교체 후 v3 재실행(1M, 3시드)으로 0.455 도달 여부.

## 새 연구(적응적 가이던스 스케줄링)에 주는 함의
- 개입 **강도**(β, λ)가 개입 **시점**(F)보다 훨씬 민감하다 — 스케줄러의 1차 제어 변수는
  강도/게이팅이어야 하고, 시점은 비용 축.
- staleness 비용은 존재하나 작다(2s3z) → 5m6m에서 재측정이 필수.
- 관측 기반 d_t로 전환해도 손실이 없으므로 실행 시 정보 누수 없는 정직한 설정으로
  베이스라인·새 방법을 모두 돌린다.
