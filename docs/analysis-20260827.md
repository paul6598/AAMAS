## 정정: 5m_vs_6m 논문 참조점 오독

state.md의 "논문 참조점: 5m_vs_6m AUC LEHCA 0.295 vs QMIX 0.039 (**7.6×**)"는
Table 4의 **열을 잘못 읽은 것**이다. Table 4의 5m_vs_6m 행:

| | Win Rate | AUC_early |
|---|---|---|
| QMIX | 0.2950 | 0.0387 |
| LEHCA | 0.3672 | 0.0612 |

즉 0.2950은 QMIX의 *win rate*이지 LEHCA의 AUC가 아니다. 실제 논문 AUC 비율은
**0.0612/0.0387 = 1.58×**다. 따라서:

- "우리 LEHCA AUC 0.299 ≈ 논문 LEHCA 0.295 거의 일치"는 우연의 산물 — 논문
  LEHCA AUC는 0.0612다.
- 우리가 관측한 1.18×는 "7.6×에 크게 미달"이 아니라 **논문의 실제 비율 1.58×에
  꽤 근접**한 값이다. 5m6m의 방향 재현은 세션 기록보다 좋은 상태다.
- state.md·최종 보고서의 해당 참조점은 수정할 것.

## 5m_vs_6m: 베이스라인 괴리가 2s3z보다 훨씬 심각

논문 레짐: QMIX는 첫 1M 동안 승률 ~0 (AUC 0.0387), **5M 최종이 0.2950**.
우리 레짐: QMIX seed0이 **1.2M 만에 final 0.589** — 논문 QMIX의 5M 최종의 2배를
1/4 학습량으로 달성. AUC(첫 1M)도 0.253으로 논문의 6.5배.

같은 Table 2 하이퍼파라미터로 이 정도 차이면, 논문의 5m6m 결과(그리고 큰 상대
격차)는 **거의 학습이 안 되는 QMIX 위에서 성립한 것**이다. 논문의 스토리
("QMIX가 못 배우는 sparse-reward 구간을 LLM 가이던스로 부트스트랩")가 우리
세팅에서는 전제부터 성립하지 않는다 — 우리 QMIX는 그냥 잘 배운다. 2s3z에서 본
패턴(우리 QMIX AUC 0.332 vs 논문 0.254)의 확대판. 이는 재현 실패라기보다
**논문 베이스라인의 약함**을 시사하는 증거로 기록할 가치가 있다.

주의: 우리 5m6m run은 1.2M이므로 **final 비교는 논문(5M)과 불가** — AUC(첫 1M)만
프로토콜이 일치한다. 최종 보고서에서 final 열을 만들려면 5M 완주가 필요하다는
점을 명시할 것 (혹은 "1.2M 시점" 라벨을 달 것).

## 2s3z v3 세부와 남은 쟁점: 마스킹의 초반 드래그

시드별 (G3 설정 = beta 0.5, λ_start 0.5→0 (decay 0.998), shaping_in_learner,
mask_anneal 150k, masked test):

| 그룹 | 시드 | AUC_early | final |
|---|---|---|---|
| DIAG_G3_combined (500k) | 0 / 1 | 0.042 / 0.317 | 0.950 / 0.981 |
| LEHCA_2s3z_v3 (1M) | 0 / 3 / 1@87% | 0.241 / 0.167 / 0.265 | 0.975 / 0.984 / 0.955* |

증거를 모으면 초반 드래그의 주범은 일관되게 **train-time 마스킹**이다:
DIAG_B(마스킹만) 정체, G1의 어닐 직후 폭발 가속(0.44→0.91), G2(마스킹 유지+β0.25,
AUC 0.273) > v3(마스크 150k 어닐+β0.5, AUC ~0.22). v3의 mask_anneal 150k는 AUC
창(0–200k)의 75%를 덮으므로 초반 드래그가 AUC에 그대로 반영된다.

이는 논문 Table 5와 정면 배치된다: 논문은 2s3z에서 마스킹을 *제거하면* AUC가
0.4549→0.3425로 **떨어진다**고 보고하지만, 우리 재현에서는 마스킹이 있을수록
초반이 **느려진다**. 셰이핑 방향(제거 시 하락)은 우리도 재현되나, 마스킹 방향은
부호가 반대다. 가능한 원인: (a) 우리 마스크 컴파일러가 논문보다 공격적(하드마스크
과다)이거나 predicate 그라운딩 차이, (b) β=0.5가 과대(soft tilt가 Q 스케일 대비
큼), (c) 논문 결과 자체의 문제. LLM 가이던스 내용이 같아도 마스크로 강제하는
것과 보상으로 유도하는 것의 차이가 이렇게 크다는 것 자체가 유의미한 관찰이다.

**남은 카드 (AUC 재현 시도)**: shaping-only + shaping_in_learner + 강한 초반
가이던스 (= DIAG_A의 붕괴 원인이 G2 처방으로 제거된 버전, 마스킹 완전 오프).
G2가 마스킹 유지 상태에서 AUC 0.273을 냈으므로, 마스킹을 아예 빼면 QMIX(0.332)
초과 가능성이 있다. 1런(500k) 가치 있음. 단 성공해도 "마스킹 없는 LEHCA"는
논문 구성과 다르므로 ablation 라인으로 보고해야 한다.

한계 인식: 우리 QMIX AUC가 0.332인 이상, 논문의 절대값 0.4549를 달성해도 비율은
1.37×가 상한선 — 논문의 1.79×는 우리 프레임에서 구조적으로 도달 불가능하다.
최종 보고서에는 절대 AUC와 비율을 둘 다 제시하고 이 점을 설명할 것.

## 실험 운영 피드백

1. **v3 시드 수**: 계획대로면 seed2를 포기하고 3s5z에 GPU를 돌려 v3는 n=3
   (0/1/3)으로 끝난다. 논문은 5런 평균. AUC 시드 분산이 극심한(0.04–0.32) 지금
   n=3은 AUC 결론에 특히 취약 — 여유 슬롯이 생기는 대로 seed2/4를 채울 것을
   권장. 최소한 보고서에 n을 명시.
2. **3s_vs_5z 참조점 주의**: Table 4에는 3s_vs_5z가 없다 (8m, 2s3z, 2m_vs_1z,
   5m_vs_6m만). 참조점은 Fig 4 커브뿐: 논문 5M 기준 LEHCA는 ~2.5M에 1.0 도달,
   QMIX는 ~1.5M까지 거의 0 후 불안정 상승. 5m6m과 같은 "우리 QMIX가 너무 강한"
   문제가 재발할 가능성이 높은 맵이다. t_max와 AUC 창(논문 20% = 1M) 정합 확인.
3. 판정 지표·프로토콜 관련 1차 분석 권고(last-10% 평균, masked test, QMIX@500k
   참조점 0.92)가 모두 반영된 것 확인 — 이후 판정도 동일 기준 유지.
