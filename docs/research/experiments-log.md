## 1. SMAC 2s3z 진단 프로브 (2026-08-31, temp 0.2, 휴리스틱 아군 AI, 9 ep)
체크포인트 없이도 P1은 확인할 수 있다: SMAC 내장 휴리스틱 아군 AI(최근접 공격,
`heuristic_ai=True`)로 실제 전투 궤적을 만들고, 5스텝마다 LLM을 2회(캐시 off)
shadow 호출해 기록만 한다. 매 스텝 스냅샷·avail·휴리스틱 행동·이벤트·φ를 남기므로
고정 F / F=ep / 이벤트 / CUSUM(φ) / 단발 임계값을 **오프라인 재생**해 (호출/ep,
효과 낡음) 표를 뽑을 수 있다. 정책이 없으므로 틸트 argmax는 못 재고 hard 불일치·
prefer 불일치·"낡은 g가 신선 g\*의 선호를 금지"(forbid_conflict)·"휴리스틱 행동을
낡은 마스크가 금지" 비율을 쓴다. P2(성능)는 여전히 체크포인트가 필요.
- 코드: `algorithm/vigil/probe_phase.py`(수집), `analyze_probe.py`(분석).
- 런: 2s3z 20 ep, cpu1 노드, LLM n020:8356 → `results/vigil/probe_2s3z_heur_s0.jsonl`.
- 판정은 E1과 동일(D_stale ≥ 2·D_noise, 이벤트 정렬). 추가로 재생표에서 CUSUM이
  같은 호출 수의 고정 F·이벤트 트리거보다 낡음이 낮은지 본다.

**베이스라인 세션 발견(8/31 19:28)이 E2 설계에 주는 제약**: 에피소드 시작 상태는
항상 동일(풀피·적 시야 밖 → 키 "nosight")이라 **F=ep + 캐시 on이면 매번 캐시
적중 → 단일 정적 계획**이 된다. E2의 A1(F=ep)은 캐시 off 또는 에피소드 시작 시
강제 재호출로 정의해야 하고, 캐시 적중을 "호출"로 세지 않는 비용 정의도 명시.
또한 베이스라인이 이미 β=0.1 마스킹 on에서 훈련 시 F∈{25,50,100} 런을 돌리고
있어(F25_full/F25_shaping/F100_full, 8/31), S4의 훈련 시 F 곡선 일부가 그쪽에서
나온다 — 중복 투입 금지, 결과는 인용.


결과: 같은 상태 2샘플 hard 불일치 0.31 ≈ D_stale(0.25–0.37) → temp 0.2에서는 접지 노이즈가 낡음을 가림. 전략 문장은 안정, forbid 토큰은 무작위. 서브골은 에피소드 내내 고정(2s3z에는 국면 전환이 없음). 파일 results/vigil/probe_2s3z_heur_s0.jsonl.

### 전환 사유
2s3z 프로브(9 ep)에서 (i) 올바른 규칙이 에피소드 내내 불변, (ii) temp 0.2 접지 노이즈
(같은 상태 hard 불일치 0.31)가 낡음과 같은 크기로 확인되어, 에피소드 내 급변(소유권
전환 ν)이 내생적으로 존재하고 낡은 규칙이 능동적으로 해로운 GRF로 옮긴다. 설계와
실행 기록은 docs/research/grf-testbed.md. 아래 E1/E2 프로토콜은 GRF에 그대로 적용하되
ν는 소유권 전환으로 자동 라벨하고 temperature 0을 전제로 한다.

### 2c. 신선한 가이던스의 상태 적합성 (temp 0, 7 ep, 796 시점; `analyze_guidance_quality.py`)
- 국면 인식: ours→ATTACK 99%, theirs→DEFEND 98%, loose→TRANSITION 38%/DEFEND 40%/ATTACK 20%.

## 3. 재생표의 계산 방법 (analyze_probe.py `replay`)
- 같은 로그(10 ep × 1000스텝, 10스텝마다 LLM 출력 2회 기록)를 스케줄별로 다시 돌린다.
  트리거가 울리면 "갱신 대기", 실제 갱신은 다음 shadow 시점에서 그때 기록된 LLM 출력을
  보유 가이던스로 채택. 첫 shadow 시점은 무조건 갱신.
- 호출/ep: 채택 횟수 평균. 낡음(prefer/hard): 각 shadow 시점에서 보유 g와 신선 g\*를
  같은 상태로 컴파일한 마스크가 다른 (에이전트×행동) 칸 비율(effect.py `mask_distance`).
  forbid_conflict: 보유 g가 금지한 행동을 g\*가 선호하는 에이전트 비율.
- ν: 이전 소유 팀이 공을 잃은 첫 스텝(이후 상대에게 정착한 경우만). 지연 = ν 이후 첫
  갱신까지 스텝(없으면 에피소드 끝까지). 오경보 = 직전 20스텝에 ν가 없는 갱신.
- 트리거: fixed F / event(possession 값 변화 전부) / event2(반대 팀 정착) / φ-CUSUM /
  단발 임계값 / sgapp(손 표 전제조건 비율<θ) / sgappcusum((1−frac) CUSUM) /
  sgapp_learned(leave-one-episode-out 발화율 P̂(f_j≠0 | possession, zone) 가중 평균; θ 또는 CUSUM).
- 주의: 낡음은 마스크 효과 공간만(서브골 제외); 갱신이 10스텝 격자라 지연 최솟값 ≈5,
  절대값이 아니라 스케줄 간 상대 비교용.
