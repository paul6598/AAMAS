# LEHCA prompt reconstruction: paper_v2

## 목적과 출처

기존 `paper` 프롬프트는 보존하고, SMAC용 `prompt_style=paper_v2`를 추가했습니다.
원저자의 프롬프트 원문을 복원한 것이 아니라, 로컬 LEHCA 논문: `paper/LEHCA.pdf` (서버 보존 자료)의 설명을 현재 실행 인터페이스에 맞게 재구성한 버전입니다.

| 논문 근거 | 반영 |
|---|---|
| p.5 Prompt engineering: 역할, 목표, 구조화된 관측, 제약/선호, JSON | 명시적인 역할·정보 경계·출력 계약 |
| pp.4,6: concise rationale, 상황 분석 → 전략 → 서브골 분해 | 3단계 결정 절차와 짧은 관측 근거/전략 요약. 긴 추론 전문은 요구하지 않음 |
| p.6: 구체적·평가 가능·시간 한정 서브골, 우선순위 | 다음 갱신까지 유지될 목표, 갱신 간격/상한, 적용 가능성 확인 |
| p.6: 관측 기반 입력, true reward/privileged information 비공개 | 환경 보상식·학습 성적·숨은 상태 입력 없음 |
| pp.6–8: 자연어 조건을 predicate 및 hard/soft mask로 grounding | 현재 predicate의 부호·조건·배율과 action rule의 표현 한계 명시 |

논문이 공개한 정확한 프롬프트, predicate 목록/배율, JSON 스키마라는 주장은 하지 않습니다. 특히 현재 구현의 고정 predicate 선택기는 논문의 자유로운 자연어 보상 규칙 생성보다 제한적입니다. 이 변경은 그 제한을 숨기지 않고 LLM에 정확히 설명하는 것입니다.

## 기존 버전에서 보완한 사항

- `focus_fire`는 공격 가능한 동료가 적어도 두 명 필요합니다. 생존 전투 아군이 한 명이면 제외하도록 안내합니다.
- 생존/보호 predicate는 양의 생존 보너스가 아니라 사망/피해 페널티임을 명시합니다.
- retreat predicate의 실제 30% 임계값과 summary의 별도 low-health 분류를 구분합니다. summary 생성 코드 자체는 변경하지 않았습니다.
- action rule에는 건강·거리·시간 조건이 없습니다. ‘부상 시 후퇴’를 타입 전체의 상시 이동 선호로 번역하지 않도록 합니다.
- 방향 토큰은 고정 방향, target 토큰은 매 스텝 재해석됩니다. per-agent 최근접/최저 체력 선택이 반드시 팀 집중사격을 만들지는 않습니다.
- 보이지 않는 적을 죽었다고 간주하지 않으며, 공격 선호만으로 탐색 행동이 구현된다고 주장하지 않습니다.
- 중복, 과도한 금지, 전략/실행 필드 불일치를 점검하도록 합니다. 필요하면 빈 목록을 허용합니다.

이는 프롬프트 수준의 지침이며 강제 검증기가 아닙니다. 잘못된 출력이 없어졌거나 성능이 향상되었다고 아직 결론낼 수 없습니다. 숫자는 환경 보상이 아니라 저희가 구현한 auxiliary shaping의 정의입니다. 이를 제공하는 것은 구현 보완 선택이지 논문에서 필수로 요구한 절차는 아닙니다.

## 사용과 검증 순서

기존 실행 명령에 `prompt_style=paper_v2`를 명시합니다. 기본 설정과 기존/대기 중 실험 명령은 변경하지 않았습니다. 새 그룹명에도 `paper_v2`를 넣어 기존 결과와 분리해야 합니다. 이 버전은 SMAC 전용이며 다른 환경에 그대로 사용하지 않습니다.

1. 먼저 동일한 관측 묶음(정상 교전, 단독 생존, 저체력, 적 미관측)에 paper/v2를 반복 호출합니다. 캐시 off, 온도·모델·출력 예산은 동일하게 유지합니다.
2. JSON 파싱 실패, 단독 생존 focus_fire, 존재/관측되지 않은 타입, 조건부 전략→무조건 이동 오류, 토큰 수·지연을 비교합니다. 긴 프롬프트의 입력 비용과 출력 잘림도 확인해야 합니다.
3. 오류 감소를 확인한 뒤 고정 F와 RSVP에 같은 버전을 적용한 별도 seed-matched 비교를 진행합니다. 프롬프트 개선과 스케줄러 효과를 한 비교로 섞지 않습니다. F가 다르면 프롬프트에 표시되는 갱신 상한도 다르므로 순수 타이밍 비교 시 동일 상한의 대조군이 필요합니다.

오프라인 회귀 테스트는 템플릿 렌더링, 실제 Commander 경로 선택, 기존 paper 보존, 기존 스키마 파싱을 확인합니다. 실제 LLM 출력 품질/정책 성능 검증은 별도이며 이 변경에서 새 학습 실험은 제출하지 않았습니다.
