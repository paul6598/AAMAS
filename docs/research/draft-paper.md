## Abstract (초안)

LLM을 상위 커맨더로 두고 MARL 팀에게 서브골(보상 셰이핑)과 행동 규칙(마스크)을 주는
계층 구조(LEHCA)는 커맨더를 **고정 주기 $F_{\text{update}}$**로 재호출한다. 우리는 (i)
올바른 가이던스가 에피소드 안에서 국면에 따라 통째로 바뀌고, (ii) 국면 지속시간이
불규칙(변동계수 ≈ 1)하여 어떤 고정 주기도 호출 낭비와 갱신 지연을 동시에 피할 수
없음을 측정으로 보인다. 이를 해결하는 **VIGIL**(Value-Informed Guidance invocation)을
제안한다: 보유 가이던스의 서브골들이 **앞으로 만들 셰이핑 보상(잔여가치)**을 predicate별
가치 헤드로 추정하고, 발급 시점 대비 비율의 지속적 저하를 단측 CUSUM으로 감지해 그때만
커맨더를 재호출한다. 통계량은 리플레이 버퍼에 이미 저장되는 셰이핑 값만으로 학습되며,
도메인 이벤트 목록·손 진척 함수·컨텍스트 테이블·LLM 자기 선언을 일절 요구하지 않고,
상한 주기 덕에 최악의 경우에도 고정 주기(LEHCA)로 퇴화한다. GRF 5v5 재생 실험에서
VIGIL은 비슷한 호출 예산의 고정 주기 대비 가이던스 낡음 23%·갱신 지연 40%를 줄였다.
학습 성능에 대한 효과는 §6의 설계로 검증 중이다.

## 1. 서론

### 1.1 문제 제기
LEHCA(Bai et al., Sci. Rep. 2026)의 커맨더는 $F_{\text{update}}$ 스텝마다 구조화 요약
$d_t$를 읽고 서브골 $G=\{(g_j,w_j)\}$과 행동 규칙을 생성하며, 그 사이에는 마지막 출력을
유지한다. $F_{\text{update}}$는 고정 하이퍼파라미터다. 논문 스스로 event-triggered
Commander call을 향후 확장으로 명시했지만 구현하지 않았다.

고정 주기의 결함은 원리적이다. 가이던스의 유효 기간은 환경의 **국면**(소유권, 교전
구도)이 정하는데, 국면 지속시간은 불규칙하다. GRF 5v5 실측: 소유권 유지 구간 길이
평균 79, 중앙값 51, **CV 0.99** — 사실상 지수분포급 불규칙성. 그 결과 어떤 $F$를
골라도 두 실패가 동시에 난다:
- $F=25$: 구간의 40%를 통째로 놓치면서(구간이 $F$보다 짧음) 긴 구간에선 2.1회를 낭비.
- $F=100$: 구간의 64%를 놓침 — 국면이 바뀐 뒤 평균 $F/2$ 스텝을 낡은 가이던스로 버팀.

낡음은 실재하는 해악이다: 보유 가이던스가 현 국면과 **정반대 지시**(상대 소유인데
전진·슛 선호 등)를 하는 시점 비율이 신선 시 7.8% → 100스텝 보유 시 47% → 150스텝
54%로 증가한다(§5.2). 훈련 중 이 지시는 셰이핑 보상으로 학습 신호에 직접 들어간다.

### 1.2 왜 어려운가 — 갱신 신호 후보들의 결함
"언제 갱신할지"를 정하는 자연스러운 후보들은 각각 결함이 있다.

| 후보 | 결함 |
|---|---|
| 상태 변화 감지(φ-거리, 요약 키 변화) | 가이던스와 무관하게 욺 — "상태가 변했다" ≠ "**이** 가이던스가 무효다" |
| 리턴·Q·TD-error 감시 | 정책 학습 자체의 비정상성과 분리 불가(기존 RL 변화 감지 연구도 배치/반복 단위로만 사용) |
| 도메인 이벤트 목록(소유권 전환, 타입 전멸) | 환경마다 사람이 작성 — 일반성 상실 |
| LLM에게 유효 조건을 선언시키기 | "LLM이 유효 조건을 옳게 쓴다"는 검증 불가 가정 |
| 게이트를 RL로 학습(When2Ask류) | 별도 학습·라벨 필요, 통계적 구조 없음 |

필요한 것은 **① 현재 가이던스에 조건부이고, ② 추가 LLM 호출 없이 온라인 계산되며,
③ 도메인 지식 없이 정의되고, ④ 결정 규칙에 통계적 구조가 있는** 갱신 신호다.

### 1.3 기여
1. **문제 실증과 측정 방법론**: shadow 호출(LLM 출력을 기록만 하고 미적용)로 보유/신선
   가이던스를 같은 상태에서 컴파일해 비교하는 효과-낡음 지표, 국면 모순율, 스케줄
   재생표. 고정 주기가 국면 시점 갱신에 지배됨을 정량화.
2. **VIGIL**: 가이던스의 **잔여 셰이핑 가치** $V_F(s;G)=\sum_j w_j \hat V_j(s)$를
   predicate별 가치 헤드로 추정하고, 발급 시점 대비 비율에 단측 CUSUM을 걸어 재호출을
   결정하는 예산 제약 스케줄러. ①–④를 동시에 만족하며, 상한 주기로 LEHCA에의 퇴화가
   보장된다.
3. **실증**: 재생 실험에서 고정 주기 대비 우위(§5); 온라인 학습 비교(§6, 진행 중)로
   성능 연결.

## 2. 배경

### 2.1 LEHCA와 우리 재현
- 커맨더: $d_t$(관측 가능 정보 요약) → strategy + 서브골 {(predicate, weight)} + 행동
  규칙. 셰이핑(Eq. 1–2): $F_t=\sum_j w_j\, f_j(s_t,a_t,s_{t+1})$,
  $R_t=R^{\text{env}}_t+\lambda_t F_t$, $\lambda_t$ 감쇠. $f_j$는 "서브골 $j$에 부합하는
  **measurable event/predicate**"의 스텝당 값 — 달성형(제거·피해)은 진척 증분, 유지형
  (집중사격·보호)은 준수/위반 지표. 마스킹(Eq. 5–7): $\tilde Q=Q+\beta\log W$.
  테스트 에피소드는 갱신·셰이핑 없음.
- **재현 수치**(2s3z, 250k, AUC_early): QMIX 0.254 / 셰이핑만 **0.394** / 마스킹 β=0.5
  **유해**(0.223) / β=0.1 무해(0.342). 논문: QMIX 0.254, LEHCA 0.455, w/o mask 0.343.
  → 이득의 실체는 셰이핑 채널이다. 본 연구는 β=0(셰이핑만)으로 채널을 격리하고, 논문
  표의 "LEHCA" 행은 β=0.1 원형으로 별도 대조한다(§6.2).
- **재현 노트(접지)**: 의미 접지 모듈은 미공개·저자 무응답. 본문 서술("training
  interface의 measurable predicates로 사상", "O(K) team-level checks")과 일치하는 최소
  구현 = 고정 predicate 라이브러리 + 스키마 강제. 논문 그림의 언어적 다양성은 서술
  층으로 간주하며 실행 층의 실제 풍부함은 검증 불가(§8). 응답 캐시(cache_key)는 논문
  미구현("cached high-level guidance"를 향후 확장으로만 언급)이고 재현 측 추가다 —
  전 실험군 유지, 비용 축은 캐시 미스 실호출로 정의(§5.5).

### 2.2 순차 변화 감지 최소한
관측 $x_1,x_2,\dots$가 미지의 $\nu$ 전후로 분포가 바뀔 때, 오경보율 제약 아래 검출
지연을 최소화하는 문제. Page(1954)의 CUSUM

$$S_t=\max\bigl(0,\;S_{t-1}+\ell_t\bigr),\qquad S_t\ge h\ \Rightarrow\ \text{경보}$$

는 i.i.d. 가정 아래 최악 지연 최적(Lorden 1971; Moustakides 1986). 평균 이동형 증분은
$\ell_t=x_t-\mu_0-k$. 지연 $\approx h/\mathrm{KL}$, 오경보까지 평균 시간
$\mathrm{ARL}_0\approx e^{ch}$ — $h$를 올리면 오경보는 지수적으로 줄고 지연은 선형으로
는다. **$h$가 예산 손잡이가 되는 이유다.** CUSUM은 **방향적**이다: 어느 변화를 $H_1$로
정의했느냐가 설계이며, 양방향은 두 단측을 병행한다. 우리 관심은 "효과 정상 → 지속
저하" 한 방향뿐이므로 하향 단측이면 충분하다(§4.3의 $k-v_t$; 상향 변화는 $v_t$ 상한
절단으로 의도적으로 무시). RL 선례: Alegre(AAMAS 2021, 동역학 모델 잔차), Canonaco
(ECAI 2020, IS 리턴 검정), Li(NeurIPS 2025, Q 정상성 검정) — 모두 단일 에이전트·환경
변화 감지이며, 감시 대상이 "외부 가이던스의 유효성"인 사례는 없다.

### 2.3 위치
LLM 호출 시점을 다룬 연구는 학습 게이트(When2Ask, LLM-MARL), 고정 주기+임계(COPA),
스트리밍 순차 정지(Wang 2026, RL 없음), 파트너 모델 모순(Goel 2026)이다. "팀 공유 외부
가이던스의 유효성"을 감시 대상으로 한 예산 제약 검출은 확인된 선행이 없다. 고전 뿌리:
옵션의 가치 기반 중단(Sutton·Precup·Singh 1999), deliberation cost(Harb 2018), BDI
intention reconsideration(Kinny & Georgeff 1991 — 세계 변화율에 따라 최적 재고 빈도가
달라짐; Schut et al. 2004), 계획 실행 감시(전제조건 위반 → 재계획).

## 3. 문제 정식화

- **스펠**: 커맨더 호출 시점 $r$에 가이던스 $G_r$ 발급, 다음 호출까지 보유. 훈련 중
  정책 $\pi$는 $G_r$의 셰이핑 $\lambda_t F_t$를 보상에 더해 학습한다.
- **효과 낡음**: $D(G_r,G^*_t;s_t)$ — 보유 $G_r$과 "지금 물었다면 받았을" $G^*_t$를
  **같은 상태 $s_t$에서 컴파일**해 비교(마스크: 에이전트×행동 격자에서 선호/금지가
  다른 칸 비율; 서브골: 집합·가중 차이). 같은 상태 2샘플 거리
  $D(G^{*(1)}_t,G^{*(2)}_t;s_t)$가 노이즈 바닥선.
- **변화점 $\nu$**: 자동 라벨 가능한 국면 전환(GRF: 소유 팀이 공을 잃은 시점; SMAC:
  유닛 타입 전멸). **평가 전용** — 방법은 $\nu$를 모른다.
- **목적**: 갱신 정책 $\pi_{\text{ref}}:h_t\mapsto\{\text{유지},\text{갱신}\}$에 대해

$$\min_{\pi_{\text{ref}}}\ \mathbb{E}\Bigl[\sum_t D(G_{r(t)},G^*_t;s_t)\Bigr]\quad\text{s.t.}\quad \mathbb{E}[\#\text{호출}/\text{ep}]\le B.$$

  Lagrangian이 임계값 하나($h$)로 환원된다.
- **평가량**: (재생) 호출/ep·평균 낡음·$\nu$ 후 첫 갱신 지연·오경보; (학습) AUC_early·
  최종(last-10%)·실호출/ep·벽시계.

## 4. 방법: VIGIL

한 문장: **보유 가이던스가 "앞으로 만들 셰이핑 보상"이 발급 시점 대비 무너지는 것을
감지하면 재호출한다.**

### 4.0 무엇을 관측할 것인가 — 소거적 도출
§1.2의 요구 ①–③을 동시에 적용하면 관측 대상이 하나로 좁혀진다. 상태 변화 신호는
①(가이던스 조건부) 위반, 리턴/Q는 학습 drift와 얽히고, 도메인 이벤트·LLM 선언은
③ 위반이거나 검증 불가다. 남는 것은 **보유 서브골의 predicate 스트림
$f_j(s_t,a_t,s_{t+1})$** 뿐이다. $f_j$는 정의상 "서브골 $j$에 부합하는 사건의 스텝당
발생량"이므로 그 흐름은 *가이던스가 설계된 효과를 지금 내고 있는가*를 그대로 말해
주고, 이미 매 스텝 계산되어 리플레이에 저장되므로 추가 비용이 0이다.

### 4.1 왜 '가치'인가 — 기준(baseline) 문제
$f_j$ 스트림에서 "저하"를 읽으려면 **기준**이 필요하다. kill 헤드의 0.3은 낮은가?
— predicate마다 스케일이 다르고, 같은 predicate라도 상황마다 기대치가 다르다. 기준의
후보와 실측 결과:

| 기준 후보 | 결과 |
|---|---|
| 같은 스펠 초반 창의 평균 | **실패** — 가이던스가 기준 창 안에서 이미 무효화되면(루즈볼 가이던스 발급 → 5스텝 뒤 소유 확정) 기준이 오염돼 아무것도 못 잡음(재생: 1–4호출/ep, 지연 300+) |
| 컨텍스트별 기대 발화량 테이블 $\hat m_j(c)$ | 재생표에서는 작동했으나 **폐기** — "같은 상황" $c$의 정의, 정보성 게이트, 0의 3분류 등 설계 자유도 과다(retired.md §5) |
| **발급 시점의 자기 잔여가치** $V_F(s_r;G)$ | **채택** — 아래 표의 문제들을 가치 함수의 성질로 흡수 |

| 해결해야 했던 문제 | 잔여가치 정식화에서 |
|---|---|
| predicate 간 스케일 통일 | 분자·분모가 같은 가이던스의 가치 → 비율이 무차원 |
| "낮음"의 기준 | 같은 상황의 평균이 아니라 **발급 시점의 자기 가치** — 컨텍스트 정의가 필요 없어짐 |
| 구조적 0(종료) vs 무능한 0 | 종료(표적 전멸·소유 상실)면 미래 $f_j$가 실제로 0 → $V_F$ 붕괴 → 욺. 무능하면 발급 시점 가치도 낮아 비율 ≈ 1 → 안 욺 |
| 정책 역량 추종 | 크리틱이 현재 정책의 리플레이로 계속 갱신됨 |
| 스펠 내부 기준 오염 | $V_F$는 교차 스펠 데이터로 학습된 **함수** — 발급 순간 상황이 나빠도 그 상황의 가치를 일반화해서 냄 |

이론적으로 이것은 옵션의 **가치 기반 중단**(Sutton·Precup·Singh 1999)이다: 가이던스 =
팀 옵션, $V_F$ = 그 옵션의 (셰이핑) 가치, "가치가 발급 대비 무너지면 중단". $V_F$는
셰이핑의 포텐셜에 해당하여 동적 PBRS 논의와도 직결된다.

### 4.2 V를 어떻게 계산하는가
**핵심 관찰 — 선형성.** $F=\sum_j w_j f_j$가 가중치에 선형이므로, 가이던스와 무관한
**predicate별 가치 헤드**만 학습하면 임의 가이던스의 잔여가치가 합성으로 나온다:

$$\hat V_j(s)\ \approx\ \mathbb{E}\Bigl[\textstyle\sum_{u\ge t}\gamma_F^{\,u-t}\, f_j(s_u,a_u,s_{u+1})\ \Big|\ s_t=s,\ \pi\Bigr],\qquad V_F(s;G)=\sum_j w_j\,\hat V_j(s).$$

(합성은 셰이핑의 총합 절단 ±clip이 발동하지 않는 범위에서 항등 — 통상 범위에서 절단은
꼬리 스파이크 안전판으로만 작동. 가이던스 임베딩·컨텍스트 정의가 필요 없다.)

- **네트워크**: 입력 = 상태 특징 $x(s)$ — $d_t$를 만드는 것과 같은 수치 공간(크리틱이
  못 보는 변수는 커맨더도 못 본다). 출력 = 라이브러리 크기만큼의 헤드(GRF 9개; SMAC은
  공통 5개 + 타입별 kill/damage/protect — 맵의 유닛 타입이 유한하므로 닫힌 목록).
  128×128 MLP 하나.
- **타깃**: 러너가 매 스텝 계산하는 predicate 벡터 $\mathbf f_t$를 저장했다가 에피소드
  종료 시 뒤에서 앞으로 한 번 훑어 할인 접미합 $Y_{j,t}=f_{j,t}+\gamma_F\,Y_{j,t+1}$.
  스텝당 학습쌍 1개 — **추가 수집·추가 호출 0**.
- **학습**: 표준화 MSE 회귀. MC 타깃이라 max 연산·부트스트랩이 없어 Q-학습보다 쉬운
  문제이고, 최근 에피소드 위주 링버퍼로 정책 변화를 추종한다(행동 정책 조건부 가치 —
  트리거 용도에는 그것이 맞는 대상).
- **지평 $\gamma_F$는 1급 설계 변수**: $\gamma_F=0.97$(~33스텝 지평)은 미래 셰이핑이
  소유권 뒤집힘에 지배되어 예측 불가(LOO $R^2=-0.16$, 실패); $\gamma_F=0.8$(~5스텝)에서
  $R^2=0.66$, 조밀 헤드 0.6–0.94(§5.4). 트리거가 필요로 하는 것은 "**현 국면의**
  생산성"이므로 짧은 지평이 용도에도 맞다.

### 4.3 결정 규칙
발급 시점 자기 가치로 정규화한 잔여 비율에 하향 단측 CUSUM:

$$v_t=\min\Bigl(1,\ \frac{V_F(s_t;G)}{\max\bigl(V_F(s_r;G),\ \varepsilon\bigr)}\Bigr),\qquad
S_t=\max\bigl(0,\;S_{t-1}+k-v_t\bigr),\qquad S_t\ge h\ \Rightarrow\ \text{재호출},\ S\leftarrow0.$$

- $k\in(0,1)$: 발급 가치의 몇 % 아래부터를 저하로 볼지(허용 슬랙).
- $h$: 예산 손잡이 — 고정하지 않고 **온라인 예산 컨트롤러**가 조절한다. 실현된 조기
  갱신률(CUSUM 발화/ep)을 20에피소드마다 목표치와 비교해
  $h\leftarrow \mathrm{clip}\bigl(h\cdot\sqrt{\text{실현률}/\text{목표률}},\,[0.5,50]\bigr)$
  로 보정(ARL의 지수 민감도 때문에 곱셈형). 오프라인 보정이 필요 없고, 크리틱이
  성장하며 $v_t$ 분포가 변해도 예산이 유지된다. 1라운드 온라인에서 자가 수렴 확인
  (GRF: $h$ 3→7.3, 목표 2회/ep 추종).
- **판단 불가 가드(하나)**: 크리틱 워밍업 전, 신뢰 헤드(타깃 분산>0)의 가중 비중 부족,
  또는 발급 가치가 최근 가이던스 평균 가치의 일정 비율 미만(스케일 상대화)이면 CUSUM을
  쓰지 않는다 → 아래 상한 주기만 작동.
- **상한 주기(퇴화 보장)**: 판단과 무관하게 최소 $F_{\max}$마다 갱신 — 신선도 바닥은
  "$F_{\max}$ 고정 주기" 수준으로 보장되고, 학습 초기(판단 불가)에는 방법이 자동으로 그
  고정 주기로 퇴화한다(초기 부트스트랩의 해답이 가드 그 자체). $F_{\max}$는 호출 예산의
  설계점을 정한다: $F_{\max}=F_{\text{base}}$면 총 호출이 베이스라인보다 많아질 수밖에
  없으므로, 본 실험은 $F_{\max}=2F_{\text{base}}$ + 조기 갱신 예산으로 **총 refresh를
  F=100 베이스라인과 동률**로 맞추고(동일 예산, 타이밍 재배치), 넉넉한 $F_{\max}$(예
  $6F_{\text{base}}$)로 CUSUM 주도 비중을 키운 효율 설계점을 함께 둔다. 두 갱신원의
  분해(sched_fallback_per_ep vs sched_early_per_ep)를 상시 로깅해 "얼마나 방법이
  일하고 있는가"를 직접 보고한다.
- LLM 호출 실패 시 기존 가이던스·CUSUM 상태를 유지하고 5스텝 후 재시도(서버 순단 대비).

### 4.4 성질과 정직한 한정
- 검정 구도 — $H_0$: 가이던스가 발급 가치의 $k$ 비율 이상으로 효과 생성 중; $H_1$:
  지속 저하. 유계 스트림 $v_t$의 단측 Page 규칙이라 일시 저하(노이즈)와 지속 저하를
  구분한다. $v_t$의 자기상관 때문에 i.i.d. 최적성은 근사이며, $h$는 이론값 대신 예산
  컨트롤러가 경험적으로 정한다.
- 방법 품질은 **크리틱 일반화 오차에 걸려 있다**. 오차는 측정 가능(LOO $R^2$, 발급 시
  예측 vs 스펠 실현치 잔차)하고, 실패 형태는 가드에 의해 "고정 주기로 퇴화"라 안전하다.
- 남는 설계 자유도: $\gamma_F$, 네트워크 크기, $k$, 목표 조기 갱신률(예산), $F_{\max}$.
  컨텍스트 정의·이벤트 목록·손 진척 함수·게이트 문턱 3종은 **존재하지 않는다**.
- 연산 오버헤드 실측: 고정 F 대비 벽시계 GRF +16–21%, SMAC +27%(짧은 에피소드일수록
  크리틱 학습 빈도↑). 학습 빈도 조절·predicate 벡터화로 축소 여지.

### 4.5 훈련 통합(선택 축)
$\beta=0$(마스킹 off)으로 셰이핑 채널만 쓴다. 갱신·종료 시점 라벨이 있으므로 리플레이
전이마다 "그때 유효했던" 서브골로 $F_t$를 학습기에서 재계산(`shaping_in_learner`) —
낡음의 훈련 신호 오염을 추가 호출 없이 줄이는 두 번째 축(ablation 대상).

### 5.1 접지 노이즈와 temperature — 방법의 전제
| | temp 0 | temp 0.2 (논문 설정) |
|---|---|---|
| 같은 상태 2샘플 prefer 불일치(노이즈) | **0.014** | 0.059 |
| 규칙 문자열 일치 | 65% | 1% |

SMAC 2s3z temp 0.2에서는 노이즈 0.31 ≈ 낡음 규모 → 판정 불가. **temp 0을 방법의
전제로 채택**(논문 설정 0.2와의 차이는 공개, ablation에 포함).

### 5.2 낡음은 실재하고 국면에 정렬된다
- $D_{\text{stale}}$: Δ=10에서 0.071 → Δ=150에서 0.167(노이즈의 12배).
- 소유권 전환이 있는 창의 연속 변화 0.139 vs 무전환 창 0.045 — 낡음이 국면 전환에서 생김.
- 국면 모순율(수비 국면에 전진 선호 등): 신선 7.8% → Δ=100 47% → Δ=150 54%.
- 신선 가이던스는 국면을 읽는다: ATTACK/DEFEND 인식 98–99%, 서브골 국면 일관성 99–100%
  — 즉 "제때 다시 물으면" 유효한 답이 있다.

### 5.3 고정 주기는 시점 기반 갱신에 지배된다 — 재생표
같은 봇 궤적에 갱신 스케줄만 바꿔 재생(호출/ep | prefer 낡음 | $\nu$ 후 지연):

| 스케줄 | 호출 | 낡음 | 지연 |
|---|---|---|---|
| F=ep(1회) | 1.0 | 0.157 | 543 |
| F=100 | 10.0 | 0.111 | 45 |
| F=50 | 20.0 | 0.077 | 23 |
| F=25 | 33.9 | 0.057 | 15 |
| 소유권 전환 이벤트(도메인 지식 상한 참조) | 28.2 | 0.037 | 5 |
| 소유권 정착 이벤트(〃) | 10.6 | 0.071 | 16 |

이벤트형은 비슷한 호출 수의 고정 F 대비 낡음 −36%·지연 1/10 — 문제는 **빈도가 아니라
타이밍**이다. (이벤트 트리거 자체는 도메인 지식이므로 방법이 아니라 상한 참조.)

### 5.4 가치 크리틱 오프라인 검증 — VIGIL 통계량의 재생 성적
- 학습 가능성: $\gamma_F=0.8$에서 LOO $R^2$ 0.66(ball_progress 0.94, keep 0.71,
  defensive_shape 0.63, press 0.61; 발화가 없는 헤드는 "신호 없음"으로 분류·가드 처리).
  $\gamma_F=0.97$은 $R^2$ −0.16으로 실패 — 지평 선택 근거(§4.2).
- 재생: **vf k=0.7 h=2 → 12.4호출 | 낡음 0.086 | 지연 28** — F=100(10.0 | 0.111 | 45)
  대비 낡음 −23%·지연 −40%로 **고정 주기를 이기지만**, 도메인 지식 이벤트(10.6 |
  0.071 | 16)에는 미달. 격차 원인: 저하의 통계적 확인에 걸리는 시간 + 발급 가치가 작은
  스펠의 판단 불가. 온라인에서는 크리틱이 정책과 함께 성장하고 h 컨트롤러가 예산을
  맞추므로 최종 판정은 학습 비교(§6)로 한다.

### 5.5 캐시 관찰 — 비용 축의 재정의
temp 0 + 거친 캐시 키에서 갱신의 ~92%가 캐시 적중이다(GRF F=100: 25k 스텝에 실호출
130 vs 적중 1,487). 따라서 (i) **비용 = 캐시 미스 실호출**로 정의하고 refresh 수와
분리 보고하며, (ii) VIGIL의 주된 이득 경로는 비용 절감이 아니라 **갱신 타이밍 → 학습
신호 복구 → 성능**이 된다. 캐시는 재현 측 추가 장치임을 공개(§2.1).

| MMM2 (2M) | 국면 구조 최고(이질·타입 전멸), 학습 가능성 불확실 — 파일럿 |

### 6.3 사전 등록 규칙과 판정
- **조기 종료**: 테스트 승률 ≥95%가 3회 연속 평가에서 유지되면 그 시드 종료(포화 후
  구간은 최종 지표를 바꾸지 않음).
- **판정 게이트**: 같은 실호출대 성능 우위 → 본 프레임 / 성능 동등·호출 감소 → 효율
  프레임 / 차이 없음 → 부정 결과 + 진단(§5) 논문.
- 비용 실측: 5m6m LLM 오버헤드 +13%(재현 데이터); MMM 계열 고정 F 11–15h/1M,
  vigil 벽시계 +27%(크리틱 최적화 전); qmix는 LLM 없음(GRF 500k 45분 실측).

### 6.4 어블레이션
$k$·목표 조기 갱신률(예산 스윕), $\gamma_F$, 판단 불가 가드(봇/무작위 혼합
ε∈{1, 0.5, 0.2, 0} 역량 스펙트럼에서 조기 갱신 churn 부재·검출 유지 확인), hindsight
재계산 on/off, 잔여가치 vs 발화율 테이블 통계량(폐기판) 비교, temp 0 vs 0.2,
마스킹 on(β=0.1) 결합.

## 7. 예상 결과와 리스크
- 기대: 같은 실호출대에서 VIGIL이 국면 전환 후 셰이핑 공백을 줄여 AUC_early 우위; 최종

  국면 전환 빈도에 비례할 것.
- 리스크: (i) 낡은 서브골이 "오답"보다 "무응답"(predicate 0)에 가까우면 성능 차이가
  작을 수 있음 → 효율 프레임 착지; (ii) 테스트베드 삼박자(§6.1) 충족 실패 — GRF 5v5
  (학습 불가)·MMM(포화)에서 실제 발생, 경계 조건 데이터로 전환하고 포트폴리오로 대응;
  (iii) $v_t$ 자기상관으로 ARL 이론은 근사 — h는 컨트롤러가 경험적으로;
  (iv) 어휘 추상 수준이 낡음 크기를 좌우(GRF 저수준 어휘가 해악 일부를 제조) —
  전술 수준 어휘인 SMAC이 보완.

## 8. 한계
접지 = 고정 predicate 라이브러리(LEHCA 본문 서술 수준의 최소 재현; 원 모듈 미공개·저자
무응답으로 실행 층의 실제 유연성은 검증 불가). 방법은 접지 층에 의존하지 않는다:
실행 가능한 predicate 집합이 주어지면 그대로 소비하며, 라이브러리가 확장되면(합성
DSL·코드 생성) 새 predicate의 가치 헤드를 그 f 스트림으로 온라인 학습해 따라간다 —
그동안 해당 서브골은 판단 불가 → $F_{\max}$ 퇴화(새 predicate당 워밍업이 유일한 추가
비용). 주장은 훈련 시 학습 신호에 관한 것(셰이핑은 테스트 미적용). 예비 근거는 봇
궤적 기반이지 학습 정책이 아님. 단일 LLM(gpt-oss-20b). 연산 오버헤드 +16–27%(최적화 전).
